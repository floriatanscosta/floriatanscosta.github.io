About

Welcome! Bem-vindo! ¡Bienvenido!

On this site you will find details about my academic background, research, publications and projects. Explore the sections to learn more about my work.

This site was built entirely with open-source software. If you would like to know more, please get in touch. If you notice any display or content-organisation problem, please let me know.

Thank you for visiting, and I hope you find useful information here!

Technology

Framework-free HTML, CSS and JavaScript, hosted on GitHub Pages. Pages are generated from a single data source, which keeps the three language versions consistent.

Languages

Content is available in Portuguese, English and Spanish. Titles of publications and the names of journals, events and institutions are kept in their original language.

Accessibility

The site follows the WCAG 2.1 guidelines: keyboard navigation, adequate contrast, light and dark modes, and respect for the reduced-motion preference.

Privacy

This site uses Google Analytics to produce aggregate visit statistics. Your theme preference (light or dark) is stored only in your browser. No form collects personal data.
