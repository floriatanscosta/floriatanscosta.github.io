Sobre as Ferramentas

Pequenas aplicações web criadas para facilitar tarefas do dia a dia no laboratório e na comunicação acadêmica.

O que você encontra aqui

Gerador de assinatura de e-mail

Monta uma assinatura padronizada, com nome, cargo, vínculos institucionais, contato, logotipo e links (site, Lattes e ORCID), confere os links e copia a assinatura pronta para colar no Gmail, Outlook, Apple Mail, Thunderbird e outros clientes de e-mail. Também exporta a assinatura em PDF.

Abrir o gerador de assinatura

Custom Plate Design XML

Define os parâmetros de uma placa personalizada, mostra a grade de gotas em escala sobre a lâmina, gera o arquivo XML para o Tecan Uno Dispenser e exporta a placa, as configurações e o XML em PDF.

Abrir o gerador de XML

Como funcionam

Tudo no seu navegador

Os dados digitados são processados no seu próprio dispositivo. Nenhuma ferramenta envia informações a servidores, e não é preciso instalar nada nem criar conta.

Privacidade

As Ferramentas não usam Google Analytics nem cookies. A preferência de tema (claro, escuro ou seguir o sistema) fica salva no seu navegador; na Assinatura, os dados só ficam salvos se você marcar “Lembrar meus dados neste navegador”, e nunca saem do seu dispositivo.

Tecnologia

HTML, CSS e JavaScript sem frameworks, hospedados no GitHub Pages, com o mesmo visual do site principal, layout para celular e tema claro ou escuro.

Código e direitos autorais

O código pode ser visto no repositório floriatanscosta.github.io (pasta ferramentas/) (abre em nova aba), no GitHub, mas não é de uso livre: código, textos e imagens são protegidos, com todos os direitos reservados. Copiar, modificar ou republicar depende de autorização. Veja o Aviso de uso.
